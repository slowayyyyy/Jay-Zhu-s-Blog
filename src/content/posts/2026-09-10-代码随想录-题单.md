## 求x的n次方（递归）

```cpp
int function(int x,int n)
{
	if(n==0) return 1;
	if(n==1) return x;
	if(n%2==1) return function(x,n/2)*function(x,n/2)*x;
	else return function(x,n/2)*function(x,n/2);
}
```

```cpp
int function1(int x,int n)
{
	if(n==0) return 1;
	if(n==1) return x;
	int t;
	t=function1(x,n/2);
	if(n%2==1)
	return t*t*x;
	return t*t;
}
```

考虑以上两种实现方式，时间复杂度分别为O(n)与O(logn)。

*递归算法时间复杂度通常需要画出对应的递归树，求算树的总节点数（常利用深度m计算）*
