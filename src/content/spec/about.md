# 关于我 / About Me

你好，我是 **Jay Zhu**。

目前主要学习和研究计算机视觉、视频语言模型与时序定位，也在这里整理读过的论文、实验中的疑问和逐渐清晰的答案。技术之外，我会记录读书、生活与一些不急着得出结论的思考。

“苍蓝回廊”是我的个人写作空间。这里不追求高频更新，更希望每一篇内容都保留当时真实的观察：研究如何推进，书为什么打动我，普通日子里又发生了什么。

如果你也对论文阅读、人工智能、成长记录或安静的个人博客感兴趣，欢迎通过 GitHub 或邮件与我交流。
