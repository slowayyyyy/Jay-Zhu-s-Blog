更新：2026-10-13。后台地址：`/admin/`。

## 窗光唱片室与歌曲手记（2026-10-25）

唱片架默认每页 6 首，在“乐境门厅与聆听室 → 窗光主画面与阅读排版 → 唱片架每页歌曲数量”选择 6 / 12 / 18 / 24；两种视图共用分页，搜索与分类匹配所有歌曲。翻页按钮文字在同页的按钮与提示文字中修改。

统一圆形封面使用现有歌曲封面；图片自带白边时，到“全部前台文案与歌单 → 音乐歌单 → 对应歌曲 → 唱片架封面取景（去白边）”选择放大比例、横向及纵向焦点。《ムスビメ》已设置 145%，《たぶん》已设置 110%。取景直接作用于同一张封面，不重复上传、不删除原文件。

“苍蓝回廊设置 → 乐境门厅与聆听室 → 窗光主画面与阅读排版”直接管理亮色、手机和暗色背景与取景、背景浓度、黑胶尺寸、当前曲封套、歌词与翻译字号、歌词高度、专注入口、唱片架露出的黑胶、迷你播放器出现时机。配置已填入线上所用素材与取景，留空的暗色专用图表示自动复用亮色图。

“聆听室按钮与提示文字”管理歌词/手记页签、专注、两种视图、空手记等文字；分类名称、说明和歌曲关联仍在本页情境分类中编辑。素材库已收录“聆听室 · 窗光花影”，图片取景控件可直接选择已有素材，也能上传原图。

“苍蓝回廊设置 → 全部前台文案与歌单 → 音乐歌单 → 对应歌曲 → 听歌手记”直接编辑该歌曲的文字，可选标题、正文与参考标记。正文留空则不显示；切换歌曲时聆听室只展示当前曲目的手记，没有自动轮播或独立播放队列。

“乐境门厅与聆听室”管理手记页签开关、标题、空状态、全部手记入口和检索文案。“查看全部手记”默认收起，展开后可搜索、逐条阅读；只有点击“听听”才播放歌曲。旧房间手记、旧顶部照片与旧分类封面保留为隐藏归档，不再作为新版页面区块；清空歌曲手记后不会被旧记录回填。

## 沉浸首页与说说（2026-10-11）

“苍蓝回廊设置 → 全部前台文案与歌单 → 首页短句与文章区”中的“首页大图铺满首屏”控制图片是否占满第一屏；“首页导航按需显示”控制首屏导航的隐藏与显示。窄屏提供“导航”按钮，桌面鼠标触顶或向下滚动会显示导航，其他页面不隐藏。

短句继续使用“回廊时刻短句池”，在半透明框内自动打字、停留与退场，下一句和下一张图片同步开始。框中的左右按钮切换文图，暂停按钮同时暂停两者。GitHub、邮件、RSS 等入口读取“个人资料”的链接，避免维护两份信息。

“说说页面展示”管理页面标题、介绍和时间线/独立卡片样式；“说说”栏目继续管理每条正文、图片、地点、日期与置顶。作者名和头像读取“个人资料”。日期使用后台填写的原时间，不作二次时区换算。六条之后提供“加载更多”；每条右下角可复制链接。

说说可连续粘贴多张照片：单图保留比例，2 张并排，4 张两行，其余多图自动三列；图注在各图下方居中，点击原图可在同一条说说内切换。图片之间添加文字可分组。HEIC/HEIF 粘贴会先转为 JPEG，图片上传后即可在后台预览，不必等待网站部署。

后台“说说 → 内容”的右侧预览使用与前台相同的图片分组与网格样式，编辑过程中即时更新；Markdown 与富文本两种输入方式均保留。此控件仅替换说说预览，不更改保存的正文或文章预览。

桌面图片取景预览改为 16:9，与常见全屏首屏更接近。实际页面仍按访客屏幕比例取景，人物脸部请留在安全区；已有图片路径、焦点、缩放和素材库不变。

## Typora 文章导入与 Markdown 编辑

后台右下角的“导入 Typora 文章”打开 `/admin/typora/`。推荐选择只包含一篇 `.md` 和配套图片的文章目录；没有图片时可单独选 `.md`，图片分散时可再选“补充本地图片”。确认标题、日期、分区和标签后点击“导入为隐藏草稿”。原文件不修改，Markdown 正文不做富文本往返转换；YAML 中原有的额外字段会留在新文章文件，但后台普通编辑器再次保存时可能丢失，导入页会提醒核对。

本地 JPG/PNG/GIF/WebP/AVIF 图片会统一复制到 `public/uploads/typora/<文章标识>/`，Markdown 引用自动改为站内地址，上传与文章在一次 GitHub 提交中完成。找不到的本地图片会阻止导入；相对附件链接会提示手动检查；远程图片仍使用原地址。单图上限 10 MB、总量 40 MB、最多 80 张。同名文章或同路径图片会拒绝写入，避免覆盖。Cloudflare 构建后进入“归档文章”检查草稿，再关闭“暂时隐藏”公开。

正文编辑器可切换 Markdown 源码模式。常用 Typora 快捷键已接入源码模式：`⌘/Ctrl+B` 加粗、`⌘/Ctrl+I` 斜体、`⌘/Ctrl+K` 链接、`⌘/Ctrl+数字` 设置标题；删除线、引用、列表、代码块、公式块等也可用源码模式浮动格式栏。前台支持 GFM 删除线/任务列表/表格、`==高亮==`、`H~2~O` 下标、`X^2^` 上标和独占一行的 `[toc]` 目录。不是 Typora 的所见即所得编辑器；一些 Typora 专有扩展、手工 HTML 或外部附件仍需预览确认。

## 保存后怎样生效

后台“保存/发布”将内容提交到 GitHub main；Cloudflare Pages 构建成功后，新页面才生效。保持打开的旧页面不会自动换成新构建，请刷新。不要通过清理音乐来刷新文案。若部署失败，旧站仍保留，先检查构建日志。

### 从站内已有图片替换首页轮播与时间卡片

进入“壁纸与背景媒体”，展开桌面轮播、手机轮播或时间卡片中的一张图片，点击“从已有素材选择”。“已整理素材”来自后台“视觉素材索引”；“全部站内图片”还包含仓库 `public/uploads` 和 `public/assets/images` 中的图片。可搜索名称、用途或文件名，点击缩略图后预览会更新，并把焦点与缩放重置为居中；再按需调整取景并保存站点设置。选用已有素材不会重复上传，也不会删除原图。

“从 Mac 上传新图片”只在确实要加入新文件时使用。刚上传或刚登记到素材索引的图片，待 Cloudflare 部署完成后刷新后台，才会出现在已有图片选择区。“视觉素材索引”仅负责整理名称和用途，单独修改索引不会改变前台正在使用的图片。

### 首页文字与图片同步（2026-09-04）

首页按“逐字出现 → 完整停留 2 秒 → 逐字退场 → 下一张图与下一句首字同时开始”的节奏播放。长句自然需要更长时间，无须在后台计算秒数。中文、日文、英文与组合 emoji 都按完整字符处理。

仍在原来的位置管理短句池、桌面图片和手机图片，各自顺序循环，数量不必相等。只有一句时重复该句配合换图；只有一张图时保持图片、继续轮播短句。短句池清空后使用备用介绍。

下一张图提前加载；网速慢时两者一起等待，加载失败/超时保留旧图并继续文字，后续跳过失败图片，避免黑屏或卡死。切到其他标签页、滚出首屏或播放背景视频时暂停相应循环，返回后继续，不补播积攒的动画。

键盘左右键或在图片上横向滑动可同时切换文图；空格暂停/恢复（输入框和按钮等交互控件不会被拦截）。关闭壁纸轮播或选定固定壁纸时尊重访客选择，不强制换图。系统启用“减少动态效果”时显示完整静态文字并停止自动轮播。

隐藏首页文字或访问其他页面时，图片使用原有独立轮播间隔。本次没有恢复开场动画，也不改变音乐播放。

## 音乐管理与随机播放

- 新增：在“音乐歌单”添加一条，填写歌名/歌手，上传音乐，选择封面和歌词，再保存。R2 上传完成不代表页面已发布。
- 隐藏/恢复：在“苍蓝回廊设置 → 全部前台文案与歌单 → 音乐歌单 → 对应歌曲”打开/关闭“隐藏这首歌”。保存并部署后，门厅精选、唱片架、分类、歌曲手记、导航栏与侧栏播放器同步排除隐藏歌曲，顺序与随机播放也不会选中。关闭开关后按原位置恢复；原文件、歌词、翻译、手记与分类关联保留。全部隐藏会显示空歌单。已打开的前台页面需刷新以取得新配置；旧歌曲未设置开关时默认显示。
- 修改：展开对应歌曲，替换该条的音乐、封面、歌词或翻译；这些字段按条目配对，不按文件名猜测。
- 移出：删除整个歌单条目再保存；“清空音乐文件”只清空地址，该条不进入前台播放队列，其余字段保留。
- 云端音乐原文件不会因清空、替换、移出或修改签名而自动删除。永久清理由站长核实引用并另行明确授权；后台没有自动删除入口。
- 歌词支持直接粘贴 LRC、站内路径或 HTTPS URL；现有 KRC 已转换成 karaoke-v1 JSON，可逐字变色。原始 KRC 不能直接作为网页歌词地址。
- 每条中文翻译按解析后的歌词行顺序配对；不计 LRC 元信息。更换歌词版本后要同步调整翻译。访客可以开关翻译。
- 随机模式每轮使用 Fisher–Yates 打乱歌单，逐首取出；这一轮九首听过后再重新打乱，轮次交界避免紧接着重复同一首。
- “上一首”沿本次页面会话真实播放历史返回；返回后“下一首”先沿历史前进。手动选择未播歌曲会从剩余队列移除，避免自动抽中两遍；手动重选已播歌曲属于访客主动重复。
- 切换到随机模式从当前歌曲建立新一轮；普通页内跳转共享播放器，完整刷新会重建队列。只有一首歌时自然循环，两首时必然交替。

## 保留但停用的字段

旧 `opening`、`hero.note/primaryCta/secondaryCta`、`home` 的旧分支入口文案仍在 JSON、恢复标签与离线备份中。当前版不渲染这些旧组件，因此后台隐藏其控件，避免“能改却无效”；没有删除用户数据，也没有恢复开场动画。

“视觉素材索引”只是素材路径与用途的登记表。改其中的用途或图片不会自动替换已引用它的页面；在对应壁纸、乐境、头像、歌单或相册字段选择该素材才生效。索引变更也不会删除文件。

## 管理范围边界

后台管理大部分个人内容，不是完整运维控制台。页面结构、菜单层级、字体、主题布局、服务开关、评论服务接入等仍由代码配置；友链补充模板是高级 MDX 编辑。Bilibili 收藏与 Umami 报表在各自平台管理。服务器状态读取真实状态，不应手工填写 CPU 百分比。

OAuth、R2、Cloudflare 和 AI 接口密钥只放平台 Secret/环境变量，不能写进这里的公开 JSON。文章摘要目前是作者维护的文字，不会自动调用 GPT。
