# 乐境与聆听室：已确认的边界

本文件只约束这次乐境扩展，不改写博客的全站产品文档。

- 保留 /music/ 为门厅，从明确入口进入 /music/room/ 宽版聆听室。
- 用户确认了冷白、浅蓝、浪漫自然的音乐手记概念；不使用洛琪希人物作为聆听室画面，可少量加入花卉。
- 唱片、歌曲信息和歌词/当前曲手记组成首个播放区，其后是带情境分类、搜索和两种视图的唱片架。窗光与花卉融入背景，封套随歌曲切换；主控件可见时默认不重复显示底部迷你控件。
- 门厅和聆听室共用既有 MusicManager，切换不改变播放时间、音量、模式、歌词或翻译选择。
- 既有 14 首音乐的顺序、封面、KRC 与用户提供的中文翻译完整保留；不修改文章。
- 后台能维护标题、说明、桌面/手机背景取景、暗色画面、图片浓淡、唱片尺寸与封套、歌词字号与高度、分类、手记、展示文案、迷你控件策略、显示开关、强调色和过渡节奏。音频、封面、歌词与手记继续在对应歌曲里维护。保存通过 GitHub main 和 Cloudflare Pages 发布。
- 写作时、归途、夜里是可替换的参考分类；示例手记不冒充作者经历。
- 听歌手记附属于每首歌，后台在对应歌曲里编辑；前台“手记”页签只显示当前歌曲手记，无内容时给出空状态。全部手记通过默认收起、可搜索且限高的入口浏览，不自动轮播或改变播放顺序。
- 尊重减少动态效果和移动设备。沿用博客的导航、明暗主题和后台认证，不另建站点或权限体系。
- 唱片架封面统一圆形并清除展示白边；默认分页每页 6 首，手机横向浏览当前页，搜索/分类覆盖全库。歌词/手记页签始终位于内部滚动区域之外，不能用顶部留白代替结构分区。
